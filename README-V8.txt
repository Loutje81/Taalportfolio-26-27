TAALPORTFOLIO V8 – bugfix bewaren + peerfeedback

Wat is hersteld:
- De knop Bewaren leest nu de echte keuzelijst voor Werkpunt uit.
- Naam en klas worden vóór het bewaren opnieuw in het profiel opgeslagen.
- Peerfeedback zoekt klasgenoten op basis van alle reeds bewaarde portfolio-opdrachten, niet alleen spreektaken.
- Een leerling kan dus al herkend worden zodra hij/zij minstens één opdracht in het portfolio heeft bewaard.
- Als de leerling wel herkend is maar nog geen spreektaak heeft bewaard, meldt de website dat duidelijk.
- Cacheversie v8 toegevoegd zodat GitHub Pages de nieuwe JavaScript zeker laadt.

Upload minstens app.js, index.html en leraar.html.
Behoud je bestaande config.js als daar je Supabase URL en anon key in staan.
